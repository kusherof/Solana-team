# Что делать на неделях 3–7 и как проверить

Код лежит в папках `week3-…` … `week7-…`. Ниже — простыми словами.

На этом компьютере **нет Solana CLI и Anchor**, поэтому недели 4–6 я собрал как готовые проекты, но **задеплоить в Devnet нужно у себя** после установки инструментов. Неделя 3 уже проверяется `cargo test`. Неделя 7 — скрипт на Node, если есть кошелёк и airdrop.

Не открывай `.exe` в редакторе — это сборка, не исходник.

---

## Неделя 3 — Rust CLI

**Надо:** маленькая программа в терминале на Rust, с вещами как в Solana (адрес 32 байта, инструкции, PDA). Сеть не нужна.

**Как проверить:**

```powershell
cd week3-solana-cli
cargo test
cargo run -- keygen
```

5 тестов должны быть ok. `keygen` печатает адрес. Дальше по README: airdrop / transfer / pda / profile — всё в файле `ledger.json` рядом, это фейковая «сеть».

---

## Неделя 4 — первая программа в Devnet

**Надо:** свой смарт-контракт и деплой, не локальный CLI.

**Как проверить код без деплоя:**

```powershell
cd week4-first-program
cargo test --features no-entrypoint
```

**Как проверить по-настоящему:** поставить [Solana CLI](https://solana.com/docs/intro/installation), `solana config set --url devnet`, airdrop, потом `cargo build-sbf` и `solana program deploy`. Program Id открыть в Explorer (Devnet). Клиент:

```powershell
$env:PROGRAM_ID="..."
npm install
npm run demo
```

Ждёшь `count 1` и ссылку на транзакцию.

## Неделя 5 — Anchor Counter

**Надо:** тот же смысл (счётчик), но через **Anchor**, плюс клиент, который дергает программу.

**Как проверить:**

```powershell
cd week5-anchor-counter
yarn
anchor build
anchor test
anchor deploy
yarn client
```

Тесты и `count 1` в клиенте. После деплоя не забудь свой Program Id в `declare_id!` и `Anchor.toml`.

---

## Неделя 6 — профиль на PDA

**Надо:** аккаунт профиля, адрес которого считается из seeds `["profile", твой pubkey]`.

**Как проверить:**

```powershell
cd week6-pda-profile
yarn
anchor test
anchor deploy
yarn client
```

Клиент печатает PDA. В Explorer owner аккаунта — программа, не кошелёк. Повторный `initialize` на тот же PDA должен упасть.

## Неделя 7 — свой токен

**Надо:** выпуск токена, перевод, metadata, клиент. Здесь Token-2022 (Token Extensions), своя program не обязательна.

**Как проверить:**

```powershell
cd week7-spl-token
npm install
npm start
```

В консоли имя `Solana Team Token`, mint в Explorer Devnet. `last-token.json` сохрани в отчёт.
