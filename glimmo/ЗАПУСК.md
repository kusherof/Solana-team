# Как запустить Glimmo

Инструменты те же, что для Liquidity Vault (WSL Ubuntu, Rust, Solana CLI 2.1, Anchor 0.31.1, Node). Если они ещё не стоят, установите их по шагам 1–2 из [../week8-15-liquidity-vault/ЗАПУСК.md](../week8-15-liquidity-vault/ЗАПУСК.md).

Все команды вводятся в Ubuntu. Открыть её из PowerShell можно так: `wsl -d Ubuntu`.

---

## 1. Показать игру без блокчейна (1 минута)

```bash
cd ~/Solana-team/glimmo/app
npm install
npm run dev
```
Откройте ссылку `http://localhost:5173`. Режим **Демо** включён по умолчанию: два готовых питомца, ускоренные таймеры, всё хранится в браузере. Витрина случайных ДНК открывается по адресу `http://localhost:5173/?gallery`.

---

## 2. Тесты программы (около 5 минут в первый раз)

```bash
cd ~/Solana-team/glimmo
npm install
anchor keys sync        # создаст ключ программы и пропишет её адрес
npm test
```
Ожидаем: `16 passing`.

Юнит-тесты формул (голод, опыт, гены):
```bash
npm run test:unit
```

---

## 3. Деплой в devnet

**3.1. RPC и баланс.** Публичный devnet RPC часто отвечает «429 Too Many Requests», поэтому лучше взять свой ключ Helius (бесплатный).
Ключ не записываем в файлы репозитория, только в переменную окружения:
```bash
export RPC="https://devnet.helius-rpc.com/?api-key=ВАШ_КЛЮЧ"
solana config set --url "$RPC"
solana balance
```
На деплой нужно около **4 SOL** devnet. Если не хватает, пополните кошелёк на https://faucet.solana.com.

**3.2. Сборка и деплой**
```bash
anchor keys sync
npm run build            # anchor build + копирует IDL в app/src/idl
anchor deploy --provider.cluster "$RPC"
```
В конце будет `Program Id: ...`, это адрес программы.

**3.3. Создать игру** (конфиг, mint еды FOOD, казна; параметры подобраны для живого показа: яйцо вылупляется за 1 минуту, кормушка раз в 10 минут, «день заботы» длится час). Запускать нужно тем же кошельком, которым деплоили: создать игру может только upgrade authority программы.
```bash
ANCHOR_PROVIDER_URL="$RPC" ANCHOR_WALLET=~/.config/solana/id.json npm run devnet:init
```
Адреса и ссылка на транзакцию сохранятся в `deployments/devnet.json`.

## 4. Играть в devnet через Phantom

```bash
cd app
echo "VITE_RPC_URL=$RPC" > .env      # .env не коммитится
npm run dev
```
1. В Phantom: Настройки → Режим разработчика → **Devnet**.
2. Пополните Phantom на https://faucet.solana.com (хватит 1 SOL).
3. На сайте переключитесь на **Devnet** и подключите кошелёк.
4. **Новое яйцо** (0.05 SOL) → **Кормушка** выдаёт 10 FOOD (она открывается после первого яйца) → через минуту **Вылупить** → **Покормить** и **Играть**.
5. Каждая строчка в журнале ведёт на транзакцию в Explorer. NFT питомца видно в Phantom во вкладке коллекций.
6. Чтобы скрестить, вырастите двух питомцев до 5 уровня.

## 5. Открыть с телефона

- **Демо** без кошелька: ссылка в описании PR, открывается в любом браузере телефона.
- **Полная версия на GitHub Pages.** После слияния PR в `main` откройте в репозитории **Settings → Pages → Source: GitHub Actions**. Workflow «Glimmo Pages» соберёт сайт, и он будет доступен по адресу https://kusherof.github.io/Solana-team/
- **Devnet на телефоне.** Установите Phantom, включите в нём Devnet, откройте сайт и нажмите «открыть игру в Phantom»: страница откроется во встроенном браузере Phantom, и кошелёк подключится.

## Если что-то не так

| Проблема | Что делать |
|---|---|
| `429 Too Many Requests` | Используйте свой RPC (Helius), см. шаг 3.1 |
| «Игра ещё не создана в devnet» | Выполните шаг 3.3 |
| После `anchor keys sync` сайт не видит программу | Ещё раз `npm run build`: он копирует IDL с новым адресом в `app/src/idl` |
| `insufficient funds` при деплое | Пополните кошелёк devnet SOL |
| `NotAdmin` при `devnet:init` | Запускайте кошельком, которым деплоили программу (upgrade authority) |
| Порт 8899 занят при тестах | `pkill solana-test-validator` и повторите `npm test` |
